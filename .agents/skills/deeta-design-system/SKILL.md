# Sistema de diseño de DEETA

DEETA debe transmitir control, claridad y movimiento. Debe sentirse diseñado específicamente para administrar negocios, no como una plantilla de dashboard ni una aplicación AI genérica.

## Criterios visuales

- Construir jerarquía con composición, tipografía, espacio, contraste y tamaño.
- Mantener pocos tokens visuales, consistentes y con una función clara.
- Usar una sola familia coherente de íconos vectoriales; no usar emojis en la interfaz.
- Hacer que éxito, alerta, error e información sean reconocibles también mediante iconografía, texto o forma, no solo color.
- Usar movimiento y microinteracciones únicamente para explicar una acción o cambio de estado.
- Diseñar primero según la función de la pantalla y reutilizar componentes cuando la función realmente coincida.
- Hacer que los datos importantes se entiendan rápidamente y acompañar las cifras con contexto.

Evitar como lenguaje principal: degradados violetas o azules asociados a productos AI sin una razón de marca, glassmorphism, exceso de cards, radios exagerados, sombras decorativas fuertes, superficies totalmente blancas sin jerarquía y tableros saturados de cifras sin explicación.

## Antes de modificar una pantalla

1. Entender su objetivo y la decisión que debe facilitar.
2. Identificar una acción principal.
3. Quitar o relegar información secundaria innecesaria.
4. Definir la jerarquía visual.
5. Resolver primero la experiencia móvil.
6. Adaptar escritorio aprovechando el espacio disponible.
7. Revisar consistencia con las demás áreas de DEETA.

No cambiar la identidad existente de forma amplia si la tarea solicita solamente una corrección localizada.
